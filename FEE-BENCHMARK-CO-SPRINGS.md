# Fee benchmark — Colorado Springs / Front Range (law-firm marketing ops)

**Last checked:** July 15, 2026  
**Purpose:** Set Gilbert Guide **Est. cost** / project fees against Cos Springs + Front Range agency norms for a criminal-defense / multi-channel legal practice (Pav Law).

## Market bands (public)


| Lane                          | Typical Cos Springs / Front Range                                                         | Notes                                                               |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| PPC / ads management          | **$1,000–$5,000/mo** (local); Denver often **$1,500–$5,000/mo** or **15–20% of ad spend** | Entry SMB packages ~$600–$997/mo; law verticals sit mid–upper       |

| Social (organic + light paid) | **$2,500–$6,000** setup · **$500–$1,500/mo**                                              | Law-firm creative + compliance adds premium                         |


**Pav media context:** client platform spend often ~**$16k–$24k/mo** (Search + LSA near May ~$20k plan). At 15–20% of $20k, management alone would be **$3,000–$4,000/mo** — GGL retainer should not undercut that band while still bundling LSA ops.

## Comparison verdict (short)

- **Retainer $2,700 → recommend $2,900/mo** — mid Cos Springs for multi-platform **law** ads; still below a pure %-of-spend model at Pav’s media level.
- **HubSpot parent HsSetup $4,500 → $5,500** — package price so SummerEmail/HsContacts/HsPipe/HsLanding are not re-sold as orphan agency fees.
- **$0 fees (LsaCall, SwagPrint)** need a listed Est. cost or they read as “free labor” in the Guide.
- **Project band $1,000–$3,800** is generally right for Front Range legal ops; lift underpriced foundational sprints (dashboard, VoIP, landing, LSA training).

## How to use

1. **INDEX → Est. cost** — Guide quote from **Est. cost (Guide)** column above.
2. Project `.md` **Fee** / **Ongoing fee** — synced to that Guide figure (Jul 15, 2026 Action pass).
3. Keep **platform ad spend** and **print/merch production** off consulting invoices.
4. Package HubSpot children (**SummerEmail, HsContacts, HsVoip**, plus HsPipe story) under **HsSetup** — do not re-sell as orphan agency fees.
5. **SocialAds** monthly production stays inside **RETAINER** — do not quote a separate social ongoing.

### Live market estimate (auto)

On every `npm run build`, each project gets a **market estimate** from:

- **Local** CO Springs / Front Range band mid (55%)
- **National** law-marketing band mid (45%)
- **Scope multiplier** from Value Added, Tasks/WIP, Completed, Information needed, AB-Qs, KPIs, description depth
- **Complexity** bumps (compliance, HubSpot+VoIP, sensitive practice, multi-channel)

That figure shows on Guide cards as **Market $…** next to the locked quote. It does **not** overwrite Fee or INDEX.

```bash
cd gilded-goose/clients/pav-law/project-picker
npm run build          # refresh Market on cards
npm run estimate-fees  # table: Quote vs Market vs Δ
```

When you accept a new quote: copy Market → project **Fee** and INDEX **Est. cost** (nearest $100).
