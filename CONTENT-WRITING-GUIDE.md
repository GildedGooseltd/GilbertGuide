## 1. Voice & claims


| Do                                                                     | Don’t                                                       |
| ---------------------------------------------------------------------- | ----------------------------------------------------------- |
| Colorado · Colorado Springs · Fort Carson · El Paso County when true   | Vague “nationwide” or empty “top firm”                      |
| Urgency for criminal moments: arrested · charged · under investigation | Scare copy or outcome promises                              |
| Value: rights · record · future · career / clearance for military      | Lead with fees, financing, or discounts                     |
| Free confidential case evaluation as CTA                               | “Best defense,” “experience matters,” “passionately defend” |
| Prefer Lawyer in typed keywords when both exist                        | Stack Attorney + Lawyer twins on the same intent            |
| One job per piece                                                      | Criminal + divorce + fees in one Yelp blurb                 |


Firm age: Pav Law is a newer brand. Do not claim long firm tenure. Ground trust in local defense work, clear next steps, and reviews — not “years of experience” language for the firm name.

Bar-safe: no guaranteed outcomes, no “we’ll get it dismissed,” no fake #1 claims.

## 2. Yelp Ads — deep rules



### How Yelp bills and shows ads


| Fact                                                    | Rule for Pav                                              |
| ------------------------------------------------------- | --------------------------------------------------------- |
| CPC against a monthly max budget                        | Views free; pay on click                                  |
| Boosted keywords steer budget toward those searches     | Not a separate fee line                                   |
| Ads appear in Sponsored Results and on competitor pages | Copy must stand next to rivals                            |
| Custom text, featured review, or Yelp auto-pick         | Prefer custom text for criminal control                   |
| Photo is part of the ad                                 | Use a clear, professional photo; test against review text |




### Limits & truncation


| Limit                                                                      | Practice                                                |
| -------------------------------------------------------------------------- | ------------------------------------------------------- |
| Custom text ~15–1500 characters                                            | Write full value in the body; win the click in the open |
| Mobile truncates early — treat ~120–180 characters as the “above the fold” | Put hook + value + CTA start in the first two sentences |
| No URLs in custom text                                                     | Phone and evaluation CTA in words only                  |
| Avoid ALL CAPS and number-only text                                        | Title case / sentence case                              |


Specialties field: Yelp may pull ~first 200 characters of Specialties into some ad formats. Keep Specialties aligned with boosted criminal lanes.

### What performs on Yelp for this firm

Research pattern for local professional ads + Pav Ads keyword evidence:

1. Hook the crisis in line one — arrested / charged / under investigation
2. Name the lanes that match spend winners — military · DV · assault · felonies
3. State the value — protect rights, record, future
4. One clear CTA — free confidential case evaluation
5. Optional second beat below the fold — Colorado courts, military stakes — not price

Test one change at a time: custom text vs 5-star review snippet; photo A vs B. Measure leads and calls, not impressions alone.

### Review ads vs custom text


| Option                  | When to use                                                                 |
| ----------------------- | --------------------------------------------------------------------------- |
| Custom text             | Default for criminal — controls charge types and CTA                        |
| 4–5 star review snippet | When a review names defense quality without wrong practice areas            |
| Yelp auto-optimize      | Only as a timed test; do not leave on if it surfaces fees or off-offer work |


Respond to every Yelp review. Active replies support trust on the listing the ad sends people to.

Yelp often strips line breaks in Specialties and similar fields. Write short sentences. Put the hook in the first ~200 characters. Mid-dots · help lists stay readable in one block.
