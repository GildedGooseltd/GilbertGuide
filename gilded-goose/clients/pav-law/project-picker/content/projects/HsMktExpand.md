## Project Plan

### Forum / Q&A attribution · 10/22/2026

Find customers with useful answers on Reddit · Quora · Justia questions. Track in HubSpot the same way as other channels.

1. Add `pl_lead_source` options: Justia Answers · Quora · Reddit. Keep Justia for directory / CH-DIRS only.
2. Create Marketing Campaign `Forum outreach`. Associate hire / NTGUILT forms.
3. Stamp every outbound profile or answer link: `utm_source` = reddit | quora | justia · `utm_medium` = community · `utm_campaign` = forum-outreach · `utm_content` = subreddit or topic slug.
4. Form workflow: community medium + those sources → set Lead source · ticket Category New inquiry · Help Desk Prospects pipeline already wired for forms.
5. Add How did you hear options for Reddit · Quora · Justia Answers for phone-only converts.
6. Report: contacts and tickets by those Lead sources · Campaign membership · form submits by `utm_source` · Deals after Retained.
