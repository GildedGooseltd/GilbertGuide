## Description

A web lead only becomes revenue if intake moves fast. Research on <a href="https://blog.HubSpot.com/sales/inbound-sales" target="_blank" rel="noopener">speed to lead</a> shows response within five minutes dramatically improves qualification rates — yet Pav Law's HubSpot workflows, Romina booking link, and referral import path are not fully connected. This sprint proves the full path: form submit → task → bookable consult.

## Value Added

- Proves web lead → HubSpot task → Romina booking without handoffs
- Faster follow-up recovers leads that would have gone cold
- Foundation before scaling paid spend further
- Deliverable: W1 and W4 workflows live and tested with sample leads
- Deliverable: Romina HubSpot meeting page and calendar connected
