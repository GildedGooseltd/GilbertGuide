## Description

Generic ad copy underperforms because it does not prove results. Social proof — outcome type and jurisdiction, never client names — builds trust within ABA advertising rules. This project creates an approved win log and rotating ad snippets.

Social proof — outcome language without client names — builds trust in professional services ads. HubSpot’s social proof research and ABA Rule 7.2 set the boundary between persuasive copy and impermissible advertising claims. See HubSpot — social proof examples and ABA Model Rule 7.2 — advertising.
