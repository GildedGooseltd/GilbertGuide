Owner webhook setup

One-time. Makes live Feedback mode Save write to the shared MetricsFeedback sheet for every reviewer on the public URL. Not a Google Form.

Wrong repo causes empty webhook. Secrets must be on PickyPavi only — not GilbertGuide. Live config is pages-config.js (not config.js).

1 — Get the Apps Script /exec URL

  1. Open the Sheet: Feedback / submissions spreadsheet
  2. Extensions → Apps Script
  3. Paste full apps-script-webhook.gs from this repo into Code.gs → Save
  4. Deploy → New deployment (or Manage deployments → Edit → New version if one exists)
  5. Type Web app · Execute as Me · Who has access Anyone → Deploy
  6. Copy the Web app URL ending in /exec

2 — Save Secret 1 on PickyPavi (GitHub browser)

  1. Open New repository secret (PickyPavi)
  2. Name field (exact): PAV_PICKER_WEBHOOK_URL
  3. Secret field: paste only the /exec URL — not the Sheet link, not the secret name
  4. Add secret. Already exists? Secrets list → Remove → add again (not editable in place)

3 — Deploy + verify before testing Save

  1. Deploy Gilbert Guide → Run workflow → branch cursor/op01-submission-updates (or the branch you pushed) → wait for green
  2. Open live pages-config.js
  3. Must see webhookUrl: "https://script.google.com/.../exec" — not ""
  4. Only then: live site → Metrics → Feedback mode → rate one card → Save → Sheet tab MetricsFeedback new row

Local preview alone cannot gather for other users. Shared gather needs a non-empty live pages-config.js. For Mac-only tests, copy config.example.js → config.js and paste your /exec (gitignored).
