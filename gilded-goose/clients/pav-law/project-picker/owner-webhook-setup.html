Owner webhook setup

One-time. Makes live Feedback mode Save write to the shared MetricsFeedback sheet for every reviewer on the public URL. Not a Google Form.

Secret updates do nothing until Deploy is green. Live pages-config.js only changes after a successful Deploy Gilbert Guide run. If Actions shows Missing PAV_PICKER_WEBHOOK_URL, the secret is still empty to GitHub — stop re-pasting secrets; use the committed bypass below.

1 — Get the Apps Script /exec URL

  1. Open the Sheet: Feedback / submissions spreadsheet
  2. Extensions → Apps Script
  3. Paste full apps-script-webhook.gs from this repo into Code.gs → Save
  4. Deploy → New deployment (or Manage deployments → Edit → New version if one exists)
  5. Type Web app · Execute as Me · Who has access Anyone → Deploy
  6. Copy the Web app URL ending in /exec

2 — Bypass (preferred): committed pages-config.defaults.js

  1. Webhook is public on Pages anyway. Deploy reads committed pages-config.defaults.js when the GitHub secret is empty.
  2. Kate: paste the /exec URL in Cursor chat if it needs updating — agent commits that file. Do not keep looping on Secrets.

3 — Deploy + verify

  1. Deploy Gilbert Guide → Run workflow → branch cursor/op01-submission-updates → wait for green
  2. Open live pages-config.js
  3. Must see webhookUrl: "https://script.google.com/.../exec" — not ""
  4. Only then: Metrics → Feedback mode → rate one card → Save → Sheet tab MetricsFeedback new row

Local Mac-only tests: copy config.example.js → config.js (gitignored) with your /exec.
