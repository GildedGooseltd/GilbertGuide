1. Open [https://pu.findlaw.com/welcome](https://pu.findlaw.com/welcome) · same system as [profileupdate.findlaw.com](https://profileupdate.findlaw.com).
2. If Andrew already has a Profile Update account: click Sign In · use that email · if password fails, use Reset your password on the next screen · check Spam for FindLaw mail.

### 2B · Claim then edit

1. After login: Claim a Profile to Update → choose Attorney update → Continue. For firm-wide edits, use the firm administrator / organization option if offered.
2. Find Your Attorney Profile: First Name `Andrew` · Last Name `Brown` · City `Colorado Springs` or State Colorado → Find.
3. If listed: Claim → finish verification. If not listed: Add a Profile / search again with fewer filters.
4. Manage Your Profiles → Edit next to the claimed profile.
5. Update: phone · website URL with UTMs below · bio · practice areas · FAQ/narrative if the product allows.
6. Click Publish. Most edits show quickly; affiliation changes can take up to 2 business days.
7. Enhanced / paid FindLaw packages: if Profile Update will not open a field, call 1-855-281-8859 and ask for the account manager on the Pav contract.
