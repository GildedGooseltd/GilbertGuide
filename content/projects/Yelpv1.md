## Project plan

### Scope

Whole-account Yelp paid + listing performance. Military is a keyword and copy option, not the project identity. Primary criminal voice: rights, record, future · free confidential case evaluation. See CONTENT-WRITING-GUIDE.

### $300 promo

- Apply credit while ads run; do not leave unused past the offer window
- Pair with DigProf August CTA A/B and review volume push
- Track: promo days · spend · leads · calls · cost per lead

### Platform upgrades — performance test

Test one upgrade or package feature at a time for 7 days when possible. Log leads and calls before/after.

Candidates to verify in the live Ads UI:

- Remove competitor ads / competitor page placement controls
- Specialty or category badges
- Call to Action button variants
- Custom ad text vs review snippet vs Yelp auto
- Photo choice
- Keyword boost set changes
- Geo / radius tweaks already in DigProf account

Keep only upgrades that move leads or answered calls. Drop the rest.

### HubSpot links / tracking

- Website field and Connect post Custom URL: pav.law or practice URLs with UTMs
- Default set: `utm_source=yelp&utm_medium=referral&utm_campaign=pav-yelp&utm_content=listing`
- Ad destinations: same campaign name; change `utm_content` only if A/B testing CTAs
- Create HubSpot contacts for real Yelp leads; source Yelp
- Do not put phone numbers in Yelp Connect post body if the platform blocks them — use the button URL

### Phone → HubSpot number

- Gate on HsVoip interim HubSpot number + routing and LsaCall / Casey call-answer training
- Until gate clears: keep current public path; never publish HubSpot DID on Yelp early
- After gate: route Yelp calls into HubSpot so activity logs in CRM
- DigProf holds the same gate note — execute the swap once here when training is done
