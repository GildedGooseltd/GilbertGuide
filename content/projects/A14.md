## Description

Pav Law already runs performance-based referral work (A4). This project **writes the plan**: specific cash-generating tasks, payout tiers, caps/floors, and reporting cadence for **employees** (e.g. Casey intake blocks, Romina booking conversion) and **external contractors** (e.g. Gabriel outbound, creative freelancers).

Structure options to document for Andrew:

| Tier | Audience | Example tasks | Payout style |
| ---- | -------- | ------------- | ------------ |
| **1 — Task** | Employee | LSA status cleared daily, X booked consults | Flat per task or small bonus |
| **2 — Outcome** | Employee | Lead→case attributed to intake block | % or flat per signed case |
| **3 — Contractor** | External | Qualified dial sets, creative deliverables | Per deliverable or per qualified lead |
| **4 — Revenue share** | Referral partners | Referred matter retained | % of first fee (ABA rules apply) |

See A4 performance-based payment note in INDEX. Align with ABA referral fee guidance for anything touching attorney referral relationships.
