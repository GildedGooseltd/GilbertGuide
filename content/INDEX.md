## Formulas

Use these when editing Priority / Status / fees. Gilbert “best fit” scoring reads Priority from this table.

### Priority

- Whole numbers only (`2`, `3`, …) — lower = higher urgency on the Project Outlines table and in Gilbert ranking
- Retainer / monthly-only → Priority blank as `—` (not a number)
- Completed / archived → park at `50+` so they sort below the live stack

### Status (INDEX wins over the project `.md` file)

| Status | Meaning |
| ------ | ------- |
| `Recommended` | Push next / high confidence |
| `wip` | In progress |
| `available` | Ready to sell / start |
| `Planning` | Scoped, not ready to run |
| `research` / `draft` | Soften Gilbert ranking (heavy score penalty) |
| `On Hold` | Paused |
| `Blocked - AB` | Waiting on Andrew |
| `Launched` | Live channel / campaign |
| `completed` | Done |
| `Archived` / `archived · …` | Out of active stack (history) |
| `ongoing` | Retainer / always-on |

### Fees (on project cards)

- One-time: `Fee` only
- Setup + monthly: `Fee` + `Ongoing fee` (label shows `$setup + $mo`)
- Per-campaign: `Per campaign fee` (same $ each time a campaign is added)
- Package children (e.g. A3 under B13): do not re-sell the child as a standalone agency fee

### Gilbert best-fit score (Pav Priorities shortlist)

```
score =
  max(0, 32 − priority)
+ 22 if enabler
+ min(28, goalMatch × 3)   when survey / goal text is set
+ max(0, 16 × (1 − fee ÷ maxProjectFee))
+ 14 if backed metric
+ 10 if return estimate
+ 8  if enabler and cart already has projects
− 45 if research/draft
− 50 if planning publish
− 4  if wip
```

Completed and monthly-only items are excluded from ranking (`score = −999`).
