# Priority 2 · HubSpot Setup · Lead Source, Quality, Intake, Phones

Get value from HubSpot spend. Parent index: [HUBSPOT-PROJECTS-REVIEW.md](HUBSPOT-PROJECTS-REVIEW.md).

Last updated: 09/17/2026

## Goal

Know where leads come from and which sources produce the best matters. Connect CRM, ads data, call intake, and phones so entry happens in one place going forward. Replace spreadsheet intake with HubSpot tickets and logged calls. Improve call pickup with the phone app, more numbers, and routing by topic or work type. Build the path to phase MyCase out through cleaner data, HubSpot fields, customer portal / FAQ tests, and payment options that fit a law practice.
